Projects.

Velvet

A multi-modal verifier for imperative programs in Lean 4, with Dafny-inspired syntax. It combines automation (SMT, grind) with Lean's interactive proofs. Programs can also be executed and tested with property-based testing, all within Lean.

LeetProof

An agentic pipeline for certified program synthesis (a.k.a. vericoding), built on Velvet. Multi-modality lets it validate generated specifications via randomised property-based testing before any code is synthesised, decompose the synthesis task into sub-problems guided by verification conditions, and delegate residual proof obligations to AI provers specialised for Lean.

Par_incr

A library for incremental computation in OCaml with support for parallelism, based on the paper "Efficient Parallel Self-Adjusting Computation".

Code Character

A strategy-based programming game where players control troops in a turn-based battle by writing code in C++, Python or Java. The simulator is written in C++, and the game driver in Rust, using SPMC/MPMC channels, IPC and process management.

Enma

Enma is a toy programming language written in C++ and OCaml. It has support for primitive data types Number, Boolean, and String and also has a simple type checker. The language can be transpiled to readable C++ code as well as compiled to bytecode. The bytecode emulator is written in OCaml.
